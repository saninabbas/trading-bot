📖 Help Guide (اردو)

Binance Account ko Bot se Connect karne ka Asaan Tarika

Assalam-o-Alaikum! Is guide mein hum aapko seekhayenge ke kaise aap sirf chand minutes mein apne Binance account ko is bot se connect kar sakte hain.

📱 Binance API Key Steps (Mobile App):

  1. App kholiye: Binance app mein login karke neechay 'More' icon par tap karein.
  2. API Management: Others section mein ja kar 'API Management' par click karein.
  3. Create API: Naya label dein (jaise "My Bot") aur Create button dabayein.
  4. Permissions: Edit permissions mein ja kar 'Enable Spot & Margin' aur 'Enable Futures' ko tick karein.
    ⚠️ Note: Withdraw ki permission kabhi bhi ON mat karein!
  5. Copy Keys: API Key aur Secret Key ko copy karke bot ki settings mein paste karein.

🧠 Gemini AI (Oracle) Setup:

  • 🔹 aistudio.google.com par ja kar login karein.
  • 🔹 'Get API key' par click karke apni key banayein.
  • 🔹 Is key ko bot ke Gemini section mein save karein taake AI confirm signals de sake.
💡 Pro Tip: Secret Key sirf aik baar nazar aati hai, isay kaheen mehfooz jagah foran likh lein!
